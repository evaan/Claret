# Claret

[![Server](https://github.com/evaan/Claret/actions/workflows/Server.yml/badge.svg)](https://github.com/evaan/Claret/actions/workflows/Server.yml)
[![ScheduleBuilder](https://github.com/evaan/Claret/actions/workflows/ScheduleBuilder.yml/badge.svg)](https://github.com/evaan/Claret/actions/workflows/ScheduleBuilder.yml)

A schedule builder for Memorial University students, with course search, instructor ratings, calendar exports, and shareable schedules.

- `Server/` — Go API and scrapers.
- `ScheduleBuilder/` — React frontend built with Bun.
